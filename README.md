# Tick Data CSV Reader With Statistics

The Goal: 
- Read market data from a file, parse it, and compute relevant statistics

The data sets:
- 15 September 2008 — financial crisis
- 6 May 2010 — flash crash
- 16 March 2020 — COVID market crash

The Statistics;
- Tick count	Number of market updates
- Mean inter-arrival time	Average time between ticks
- Min/max spread	Bid-ask spread behaviour
- Average spread	Liquidity proxy
- Price volatility	Standard deviation of returns
- Maximum drawdown	Largest peak-to-trough decline
- Tick frequency	Ticks per second
- Volume statistics	Distribution of reported volume

Data set source: dukascopy
